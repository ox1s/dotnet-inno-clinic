# Типо
1. Мы создаем доктора c каким-то email и accountId
2. Мы отправляем эти данные в наш rabbitMq
3. RabbitMQ берет и записывает в MongoDB account-id = email 

## ProfilesApi
MongoDB читает Profiles API, если там нет привязки account-id - email - telegramId, то мы при рассылки email каждый день 

```
Пжлст, зайдите в тегешку и отметьте свой статус 
link: ссылка_на_бота/start?='email@innoclinic.com или accountid'
как только чел ответил
тг шлет в mongodb данные с привязкой tgid
```

в следующий раз, на следующий день и BackgroundService email sender
мы смотрим, ага, есть mongoDb telegram id, значит мы отсылаем ссылку без параметра start

## TelegramBot
TelegramBot каждый день по расписанию кидает каждому человеку по mongoDB вопрос со статусом
“At work” or “On vacation”, “Sick Day”, “Sick Leave”, “Self-isolation”, “Leave without pay”
Worker отвечает и telegramBot отсылает по ендпоинту у Profiles API изменение стататуса такому-то акканту
